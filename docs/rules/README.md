# Override 2.1 规则库

本目录保存用户提供的 2026-2027 V5RC Override 2.1 版完整资料，供本项目离线开发与规则核对。规则基线日期为 2026-10-08；未据此宣称它是当前最新官方版本，也未补入附件之外的新生赛特别规则。

| 文件 | 内容与用途 |
| --- | --- |
| [override-v2.1.pdf](override-v2.1.pdf) | 用户提供的英文原版，135 页，逐字节保留，作为本目录 2.1 版核对基准 |
| [override-v2.1.en.txt](override-v2.1.en.txt) | 英文全部页面的可检索正文，保留逐页标记和原文顺序 |
| [override-v2.1.zh.pdf](override-v2.1.zh.pdf) | 用户提供的《V5RC 全域接管-2.1版本.pdf》，129 页，原文件改用便于命令行使用的文件名，内容未改动 |
| [override-v2.1.zh.txt](override-v2.1.zh.txt) | 中文全部页面的可检索正文，供术语和条款对照 |
| [../../AGENTS.md](../../AGENTS.md) | 面向开发的中文约束整理，并结合团队培训规定代码规范 |

正文是从 PDF 提取的原文，不是另行编写的规则版本。图片、示意线、颜色和部分表格的布局无法由文本完整表达；提取也可能合并词间空格或改变换行。解释条款、图示和表格时回查原版 PDF，不用提取瑕疵推导规则例外。两份 PDF 保留各自的版权说明。

## 如何查阅

先读 `AGENTS.md` 中的程序约束，再按规则编号在正文检索，并回查对应 PDF 页。文本中的 `=== PDF PAGE N ===` 表示从 1 开始的 PDF 页序号。下表均为英文版页码；中文版排版和页码不同。

| 主题 | 英文页码 | 主要内容 |
| --- | --- | --- |
| 规则效力与澄清 | 13-17 | 如何阅读手册、Q&A、资料优先级 |
| 赛局与场地 | 18-22 | 赛局介绍、场地布置和设计理念 |
| 得分 | 23-29 | `<SC1>`-`<SC8>`，安放、可见锥尖、黄色归属、中场、自动奖励和 AWP |
| 特定赛局规则 | 29-38 | `<SG1>`-`<SG13>`，起始、展开、持有、自动边界、保护区、导入和终局 |
| 安全、通用与一般比赛规则 | 38-50 | `<S>`、`<G>`、`<GG>`，场控、人工干预、接触与牵制 |
| 技能赛 | 51-54 | `<RSC1>`-`<RSC5>`，60 秒模式、导入、计分、设置与停止时间 |
| 机器人与验机 | 55-70 | `<R>`，尺寸、主控、竞赛模板、电机、供电、材料和气动 |

| VEX U 特例 | 从 85 页起 | 独立组别规则，不作为本项目默认标准 V5RC 规则 |
| 附录与术语 | 见原文后部，附录 B 从 116 页起 | Pin Half、Possession、Midfield、Endgame、Match 等定义；其他组别仅在对应模式适用 |

在仓库根目录使用以下命令即可定位条款：

```powershell
rg -n -F '<SG6>' docs/rules/override-v2.1.en.txt
rg -n -F 'Possession -' docs/rules/override-v2.1.en.txt
rg -n -F '=== PDF PAGE 31 ===' docs/rules/override-v2.1.en.txt
rg -n -F '<SG6>' docs/rules/override-v2.1.zh.txt
```

## 对照时已发现的差异

- **`<SG3>` 高度限制**：英文第 31 页规定整场任意时刻不超过 50 英寸，中文第 38 页仍留有终局中场例外。当前项目按英文 2.1 版，不实现该例外。
- **Pin Half 的计分单位**：以英文 `<SC3>` 为准，按每个已安放锥的可见锥尖计数，不能把中文表格中的“锥”直接解释为整根道具。
- **`<R11>` 子系统编号**：英文第 62 页限制的是 Subsystem 2，即 `<R1>` 定义中底盘的动力与控制系统，其电机总额定功率不超过 55W；不要照中文索引的“子系统 1”误写设备分类。

这些是本项目对所附文件的核对记录，不是新增官方裁决。英文原文自身如有歧义，应继续核实当季官方澄清，不能自行改写为确定结论。

## 维护

- 本目录中的 PDF 和全文必须保持版本对应。更新时同时记录版本、日期、影响的规则编号，并同步 `AGENTS.md` 的程序约束。
- 保留原始 PDF；不得只替换文本中的个别句子来伪造一份新规则版本。
- 标准 V5RC、技能赛、VEX U、VEX AI 分别适用各自章节及例外，不混用赛时或硬件额度。
- 新的官方 Q&A 或比赛特别规则要记录来源和适用范围。本目录目前没有额外下载官方 Q&A 页面，只包含手册原有文字和链接。
